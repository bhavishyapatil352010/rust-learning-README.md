📌 About This Repository

This repository documents my journey of learning the Rust programming language.

I'm starting with the fundamentals and gradually exploring how Rust works through practical coding experiments, small programs, and hands-on practice.

My goal is not just to learn syntax, but to understand programming concepts, build strong logical thinking, and explore systems programming.

Status: 🚧 In Progress — This repository will grow as I learn more Rust.

🎯 Goals

- Build a strong foundation in Rust.
- Understand how Rust handles memory and data safely.
- Practise problem-solving and programming logic.
- Explore performance-oriented programming.
- Eventually explore how Rust can complement my Python and AI engineering journey.
